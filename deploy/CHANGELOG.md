## v0.2.0 — 15 ก.ย. 2569 · รื้อหน้าตาใหม่ให้เป็นสีประจำบริษัท

**ทำไมถึงแก้** — เบียร์บอกว่าหน้าตาเดิม "ไม่สวย ไม่ modern" และอยากได้สีประจำบริษัท

**สีที่ใช้ — วัดจากไฟล์โลโก้จริง ไม่ได้เดา**
อ่านค่าพิกเซลใน `Logo STT.png` (1576×1613) แล้วนับความถี่:
- **แดง `#E41824`** = 39.3% ของพิกเซลที่มีสี (hue 356° · sat 80% · light 49%) → สีหลักของแบรนด์

**ทำอะไร**
- วางระบบสีใหม่ทั้งชุดเป็นตัวแปร CSS — แบรนด์ (แดง/ดำ) + สีเสริมแยกหมวดงาน
  (จัดซื้อ น้ำเงิน `#1D6FD1` · ต้นทุน ม่วง `#6B3FBF` · คลัง เขียวน้ำทะเล `#0E7C86` · งานระบบ เทา `#4A5565`)
  + สีบอกสถานะ (เขียว/เหลือง/แดง) แยกจากสีแบรนด์ชัดเจน
- **ฝังโลโก้ STT ลงในหน้าเว็บ** — ตัดเอาเฉพาะเครื่องหมายสีแดง ย่อเหลือสูง 72px = 4.5 KB
  (ไม่ต้องโหลดจากภายนอก ไม่มีวันรูปหาย)
- แถบบนเป็นไล่สีเข้ม + เส้นแดงคาดใต้แถบ · ป้ายเวอร์ชันเป็นเม็ดสีแดงเด่นชัด
- หน้าเข้าสู่ระบบทำใหม่เป็นการ์ดลอย มีโลโก้ · ช่องกรอกใหญ่ขึ้น · ปุ่มมีสถานะกำลังโหลด
- เมนูหลักแบ่งเป็น 4 หมวดพร้อมหัวข้อ · การ์ดมีไอคอน แถบสีประจำหมวด และป้ายบอกเฟส
- หน้าตรวจระบบทำใหม่ — มีแถบสรุป 4 ช่อง (ผ่านกี่ข้อ · เวลารวม · เวอร์ชัน · วันที่สร้าง) + ตารางอ่านง่าย
- ใช้ฟอนต์ Sarabun + Inter (Inter สำหรับตัวเลข ทำให้ตัวเลขเรียงตรงกันทุกหลัก)

- วางระบบขึ้นระบบให้เหมือน NOVA ทุกอย่าง: git ในเครื่อง → GitHub → clasp push → clasp deploy
  ด้วยการกด `อัปเดตระบบ.bat` ครั้งเดียว อัปทุกไฟล์พร้อมกัน ไม่ต้องทำทีละไฟล์
- ล็อกอินด้วย **รหัสพนักงาน + PIN 6 หลัก** อ่านจากแท็บ `USERS` คอลัมน์ **E (role for P&S)**

  (บทเรียน NOVA: fallback แล้วทุกคนกลายเป็น ADMIN)
- `roleOf_()` เชื่อ PIN ก่อน แล้วค่อย fallback อีเมล (บทเรียน NOVA v0.38.0)
- ค้นคอลัมน์ด้วยชื่อหัวตาราง (`colIdx_`) → เบียร์แทรกคอลัมน์เพิ่มได้ไม่พัง
- ไม่มี File ID ของไฟล์รายปีในโค้ดเลย → อ่านจาก `REGISTRY` (source=PS) ผ่าน `yearFile_()`
- `.gitignore` กัน `*.BAK` ตั้งแต่วันแรก (บทเรียน NOVA: .BAK 299 ไฟล์ = 92% ของโฟลเดอร์ 104 MB)
- `.bat` ทุกไฟล์เป็น ASCII ล้วน + CRLF

**ทดสอบยังไง**
