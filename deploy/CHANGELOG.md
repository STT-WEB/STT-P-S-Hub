## v0.6.0 — 15 ก.ย. 2569 · ฐานข้อมูลการรับเข้า + เปิดชีตดูเองได้ตอนโปรแกรมมีปัญหา

**เบียร์สั่ง** — *"ข้อมูลการรับเข้า ถ้าโปรแกรมมีปัญหา ก็ยังดูในฐานข้อมูลได้เลย จะทำยังไง"*

ทำ 2 ฝั่งพร้อมกัน: ในเว็บมีหน้าดูการรับเข้าเต็มรูปแบบ และนอกเว็บก็เปิด Google Sheet อ่านเองได้

### เจอบั๊กใหญ่ระหว่างทาง — ยอดเงินรับเข้าเพี้ยนทั้งไฟล์

ไฟล์ RR ของ My Account มีคอลัมน์ **`sumGoodamnt` (ยอดรวมทั้งใบ) อยู่ก่อน `goodamnt` (ยอดของบรรทัด)**
และมี **`vendornameeng` อยู่ก่อน `VendorName`** ตัวหาคอลัมน์เดิมเทียบแบบ "มีคำนี้อยู่ข้างใน"
จึงไปคว้าคอลัมน์ผิดที่อยู่ก่อน ผลคือ

```
ยอดรับเข้ารวม  235,096,186.61   ← ผิด (เอายอดทั้งใบมาใส่ทุกบรรทัด)
ยอดรับเข้ารวม   53,035,868.64   ← ถูก
ชื่อผู้ขาย       ว่างทั้ง 7,512 บรรทัด → มีครบทุกบรรทัด
```

แก้ที่ `colIdx_()` ใน `02-master.js` — **กวาดหาแบบตรงตัวให้ครบทุกคอลัมน์ก่อน แล้วค่อยยอมให้เดาแบบใกล้เคียง**
เป็นการแก้ที่ต้นทาง ทุกจุดในระบบที่หาคอลัมน์จากชื่อได้ประโยชน์หมด และมีเทสล็อกไว้แล้ว 4 เคส

พิสูจน์ว่าแก้ถูก: ยอดรับข้ามปีคำนวณใหม่ได้ **137 บรรทัด · 60 ใบ · ฿4,593,786.54** —
ตรงเป๊ะกับที่วิเคราะห์ด้วย Python ตอนเฟส 1 (คนละเส้นทางกันแต่ได้เลขเดียวกัน)

> บั๊กนี้ยังไม่เคยรันกับชีตจริง จับได้ก่อนขึ้นระบบ ถ้าปล่อยไปจะทำให้ **ต้นทุนเฉลี่ยทั้งระบบผิด**

### เปิดชีตดูเองได้ — `07-guide.js`

ทำกับ Google Sheet ต้นทางโดยตรง กดซ้ำกี่ครั้งก็ได้ **ไม่แตะข้อมูลเลย แตะแค่รูปแบบ**

| ทำอะไร | ได้อะไร |
|---|---|
| ตรึงหัวตาราง + ใส่ตัวกรองทุกแท็บ | เลื่อนดู 7,950 แถวก็ยังเห็นชื่อคอลัมน์ · กรอง/เรียงในชีตได้เองเหมือน Excel |
| ใส่คำอธิบายไทยใน **หมายเหตุของหัวคอลัมน์** | เอาเมาส์ชี้แล้วรู้เลยว่าคอลัมน์นี้คืออะไร — **ไม่เปลี่ยนชื่อหัว** เพราะโค้ดทั้งระบบหาคอลัมน์จากชื่อในแถวที่ 1 |

รันอัตโนมัติทุกครั้งที่กด **"ติดตั้งโครงข้อมูล"** และมีเมนู **🔗 เปิดฐานข้อมูลตรง** ในกลุ่มงานระบบ
รวมลิงก์ทุกไฟล์ทุกแท็บพร้อมจำนวนแถว ให้กดเปิดได้ทันที

## v0.5.0 — 15 ก.ย. 2569 · หน้าฐานข้อมูล PO (เห็นทุกบรรทัดจาก My Account)

**ทำไมถึงทำ** — เบียร์ถามว่า *"จะให้จัดซื้อทำงานยังไง เพราะเค้าต้องเห็นข้อมูลฐานข้อมูลที่มาจาก My Account ด้วย"*
ถูกต้อง — v0.4.0 เปิดให้เห็นแค่ **617 บรรทัดที่ค้าง** แต่จัดซื้อต้องเปิดดูได้ทั้ง **7,950 บรรทัด**
เช่น ย้อนดูว่าปีนี้เคยซื้อของตัวนี้จากใคร ราคาเท่าไหร่ มาแล้วหรือยัง ใบไหนโดนยกเลิกไป

**เปลี่ยนโครงตารางกลาง : `PS_OPEN_PO` → `PS_PO_INDEX` (32 คอลัมน์)**

ของเดิมเก็บเฉพาะบรรทัดที่ค้าง ของใหม่เก็บ **ทุกบรรทัด** — ค้างรับ · รับครบ · ปิดรายการ · ยกเลิก

| ทำไมต้องรวมเป็นตารางเดียว |
|---|
| หน้าฐานข้อมูลกับหน้าค้างรับอ่านจากตารางเดียวกัน → **ตัวเลขขัดกันเองไม่ได้** (เทสบังคับให้ตรงกัน) |
| บรรทัดที่ยกเลิก 72 บรรทัดยังอยู่ครบ ตามที่เบียร์สั่งว่า **"จ๊อบยกเลิก ห้ามซ่อนทิ้ง"** |
| อ่านแท็บเดียวได้ทั้งสองหน้า — ไม่เพิ่มภาระให้ Google Sheets |

**หน้าจอใหม่ `ui-podb.html` — 🗃️ ฐานข้อมูล PO**

- ชิปสถานะพร้อมจำนวนจริง: ทั้งหมด 7,950 · ค้างรับ 617 · รับบางส่วน 17 · รับครบ 7,261 · ปิดรายการ 0 · ยกเลิก 72
- ค้นหาทีเดียวครอบคลุม เลขที่ PO · รหัส/ชื่อสินค้า · ผู้ขาย · จ๊อบ · หมายเหตุ
- กรอง เดือน · หมวดสินค้า · ผู้ขาย (40 รายที่สั่งบ่อยสุด) · ในประเทศ/ต่างประเทศ
- เรียง 6 แบบ · แบ่งหน้า 100 บรรทัด (80 หน้า) · กดปุ่ม "แก้" ได้จากในตารางเลย
- **ส่งออกเป็น Google Sheet ตามตัวกรองที่เห็นอยู่** (`exportPoAll`) — ได้ไฟล์ในโฟลเดอร์ P&S Hub
- กรอง เรียง นับ แบ่งหน้า **ทำที่ฝั่งเซิร์ฟเวอร์ทั้งหมด** ไม่ส่ง 7,950 บรรทัดลงเบราว์เซอร์

**สิทธิ์ยังเหมือนเดิม** — สโตร์เปิดหน้านี้ได้ เห็นจำนวนและสถานะ แต่ **คอลัมน์ราคาหายทั้งคอลัมน์**
(ตัดที่ฝั่งเซิร์ฟเวอร์ ราคาไม่เคยถูกส่งออกไป) และไม่มีปุ่มแก้ ไม่มีปุ่มส่งออก — มีเทสบังคับไว้

**ชุดทดสอบใหม่ `_tests/guard-v0500.js` — 43 เคส รัน "ทั้งสายงาน" ของจริง**

ต่างจาก `guard-v0300` ที่เทสเฉพาะเครื่องจับคู่ ชุดนี้จำลอง Apps Script บน Node (`_tests/harness.js`)
แล้วรันโค้ดตัวจริงตั้งแต่ไฟล์ Excel ของ My Account → `psImportPO` → `psImportRR` → `psRebuild` →
`getPoAll` / `getOpenPO` เหมือนที่หน้าเว็บเรียก ทุกตัวเลขตรงกับที่รายงานไว้เป๊ะ

```
นำเข้า PO 7,951 อ่านได้ / 7,950 เขียน / เสีย 1 แถว (แถว 179)
นำเข้า RR 7,513 อ่านได้ / 7,512 ใช้ได้ / เสีย 1 แถว (แถว 151)
จับคู่ 7,375 · C1 7,373 · จับคู่ไม่ได้ 0 · รับเกิน 0
ตารางกลาง 7,950 บรรทัด · คีย์ poid+listno ไม่ซ้ำ 7,950/7,950
ค้างรับ 617 บรรทัด · 184 ใบ · 28,432,882.99 บาท
ยอดสั่งรวมทั้งปี 77,674,802.64 บาท (ของจริง 76,874,965.09 + ที่ยกเลิก 799,837.55)
617 + 7,261 + 72 + 0 = 7,950  ← ไม่มีบรรทัดไหนหล่นหาย
```

**ทดสอบหน้าจอ** — เรนเดอร์ด้วย Chromium กับข้อมูลจริง 7,950 บรรทัด
ไม่มี JavaScript error · ไม่ล้นขอบจอทั้งเดสก์ท็อปและมือถือ · กดชิป/กรอง/เปลี่ยนหน้า/เปิดกล่องแก้ไขได้จริง ·
เข้าด้วยสิทธิ์สโตร์แล้วคอลัมน์ราคาหายจริง · `guard-v0100` 15 เคส และ `guard-v0300` 32 เคส ยังผ่านครบ

**ต้องทำหลัง deploy** — กด **"ติดตั้งโครงข้อมูล"** อีกรอบ (สร้างตาราง `PS_PO_INDEX` ใหม่) แล้วกด
**"คำนวณค้างรับใหม่"** ตัวเลขถึงจะขึ้น
