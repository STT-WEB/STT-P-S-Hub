**ทำอะไร**
- สร้างโปรเจกต์ Apps Script ใหม่ แยกจาก NOVA ใหญ่ (Script ID `11omqFM...UT9`)
- วางระบบขึ้นระบบให้เหมือน NOVA ทุกอย่าง: git ในเครื่อง → GitHub → clasp push → clasp deploy
  ด้วยการกด `อัปเดตระบบ.bat` ครั้งเดียว อัปทุกไฟล์พร้อมกัน ไม่ต้องทำทีละไฟล์
- ล็อกอินด้วย **รหัสพนักงาน + PIN 6 หลัก** อ่านจากแท็บ `USERS` คอลัมน์ **E (role for P&S)**
- หน้าลงทะเบียนรับ PIN ครั้งแรก (ออก PIN ไม่ซ้ำ · ลงทะเบียนได้ครั้งเดียว)
- หน้าตรวจระบบสำหรับ ADMIN — วัดจริง 8 รายการ พร้อมเวลาที่ใช้เป็น ms

**กันพลาดอะไรไว้บ้าง**
- `PRICE_ROLES` ไม่มี `STORE` → สโตร์ไม่เห็นราคา และตัดที่ฝั่งเซิร์ฟเวอร์ (`requireNotStore_`)
- `getEmail_()` ใช้ `getActiveUser` เท่านั้น ไม่ fallback `getEffectiveUser`
  (บทเรียน NOVA: fallback แล้วทุกคนกลายเป็น ADMIN)
- `roleOf_()` เชื่อ PIN ก่อน แล้วค่อย fallback อีเมล (บทเรียน NOVA v0.38.0)
- ค้นคอลัมน์ด้วยชื่อหัวตาราง (`colIdx_`) → เบียร์แทรกคอลัมน์เพิ่มได้ไม่พัง
- ไม่มี File ID ของไฟล์รายปีในโค้ดเลย → อ่านจาก `REGISTRY` (source=PS) ผ่าน `yearFile_()`
- `.gitignore` กัน `*.BAK` ตั้งแต่วันแรก (บทเรียน NOVA: .BAK 299 ไฟล์ = 92% ของโฟลเดอร์ 104 MB)
- `.bat` ทุกไฟล์เป็น ASCII ล้วน + CRLF
