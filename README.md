# NOVA – PURCHASE & STORE HUB

เว็บแอปภายในสำหรับ **จัดซื้อ + สโตร์** ของ บริษัท สุธี แท็งเกอร์ แอนด์ สเปเชียลทรัค จำกัด
(แยกจาก NOVA ใหญ่ที่ทำ BOM / ต้นทุนตามจ๊อบ)

---

## เริ่มใช้งานครั้งแรก — 3 ขั้น

1. ดับเบิลคลิก **`ติดตั้งเครื่องมือครั้งแรก.bat`** — ติดตั้ง clasp (ทำครั้งเดียว)
2. ดับเบิลคลิก **`เข้าสู่ระบบ clasp.bat`** — ล็อกอิน Google ด้วย `sasipa@suteetankers.com`
3. ดับเบิลคลิก **`อัปเดตระบบ PS Hub.bat`** — อัปโค้ดขึ้นทั้งหมด + เผยแพร่เวอร์ชันใหม่

> ⚠️ **หลักฐานเดียวที่พิสูจน์ว่าขึ้นจริง = ป้ายเวอร์ชันมุมขวาบนของหน้าเว็บเปลี่ยนเป็นเลขใหม่**
> ข้อความ `DONE!` ใน .bat เชื่อไม่ได้ (เคยขึ้น DONE ทั้งที่ push ไม่เข้าเพราะ login หมดอายุ)

## ใช้ประจำวัน

**แก้โค้ดเสร็จ → ดับเบิลคลิก `อัปเดตระบบ PS Hub.bat` ครั้งเดียว** ระบบจะทำให้ 4 อย่าง:

| ขั้น | ทำอะไร |
|---|---|
| 0 | เคลียร์ไฟล์ล็อกของ git ที่ค้าง |
| 1 | สำรองลง git ในเครื่อง + push ขึ้น GitHub |
| 2 | `clasp push -f` อัปโค้ด **ทุกไฟล์** ในโฟลเดอร์ `deploy/` พร้อมกัน |
| 3-4 | `clasp deploy` เผยแพร่เวอร์ชันใหม่ให้คนใช้เห็น |

**ในเครื่อง = GitHub = Apps Script เหมือนกันทั้ง 3 ที่เสมอ**

## ถ้ามีปัญหา

| อาการ | แก้ยังไง |
|---|---|
| `clasp push FAILED` | ดับเบิลคลิก `เข้าสู่ระบบ clasp.bat` แล้วรันใหม่ |
| git ค้าง / `index.lock` | ดับเบิลคลิก `ปลดล็อก git.bat` |
| ป้ายเวอร์ชันไม่เปลี่ยน | ปิดแท็บทั้งหมด เปิดใหม่ กด Ctrl+Shift+R · ถ้ายังไม่เปลี่ยน = ยังไม่ขึ้นจริง |
| อยากรู้ว่าระบบพร้อมไหม | ล็อกอินเป็น ADMIN แล้วกดปุ่ม **ตรวจระบบ** มุมขวาบน |
